How it works

Retrieval-Augmented Generation, step by step

Before the AI answers, Grounds AI searches our papers for the most relevant passages. The model then answers from those passages and lists them as sources.

Once, when a paper is added
1

Upload

A PDF is added on the Library page.

2

Split

Each page is cut into {{ passage_words }}-word passages, with {{ overlap }} words shared between neighbours.

3

Embed

{{ embed_model }} turns each passage into a vector, saved in SQLite.

stored on this computer
Every time you ask
4

Search

Your question becomes a vector. The {{ top_k }} closest passages are picked.

5

Answer

{{ model }} answers using only those passages.

6

Cite

The file and page of each passage are shown under the answer.

Private by design

Both AI models run through Ollama on this computer. Questions and papers never leave it.

Answers you can check

Every answer lists its sources, so you can open the paper and read the exact page.

Honest about limits

The small {{ model }} model can still mix up details. Always check the cited page.
